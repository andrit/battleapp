# Archive — superseded WIP-machinima snapshots

Point-in-time snapshots of `-machinima` edit proposals, kept when a newer proposal supersedes one, so no
prior proposal — and no reason you may still want — is ever lost.

- Naming: `<wip>-machinima-v<N>.md` (e.g. `the-piece-machinima-v2.md`).
- These are **frozen**: never edited after snapshot.
- The **living** proposal stays in `wip/` beside its WIP; this folder holds the older versions it replaced.
