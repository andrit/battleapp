# Archive — version snapshots

Point-in-time snapshots of working docs (machinima files) taken **immediately before a major
restructure**, so no prior version — and no **authorNote** — is ever lost.

- Naming: `<source>-machinima-v<N>.md` (e.g. `1-first-ideas-machinima-v2.md`).
- These are **frozen**: never edited after snapshot.
- The **living** working doc stays in `compost-heap/` and carries a `## Changelog` noting each version.
